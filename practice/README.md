# Phase 0 practice

Language warm-ups, not part of the blog. Each file has TODOs and a self-check at the
bottom: fill in the TODOs, re-run, repeat until everything prints PASS.

Work through them in this order:

```bash
node practice/js/00a-javascript-basics.js     # start here if JS syntax is new
node practice/js/00-worked-examples.js        # patterns needed by 01-basics.js
node practice/js/01-basics.js                 # array methods, spread, destructuring, ?. and ??
node practice/js/00b-async-worked-examples.js # patterns needed by 02-async.js
node practice/js/02-async.js                  # promises, async/await, try/catch, Promise.all
py practice/python/01_basics.py               # classes, properties, decorators, comprehensions
```

The three `00*` files are reading, not exercises — there is nothing in them to fix:

- `00a-javascript-basics` — variables, functions, objects, arrays and callbacks from zero
- `00-worked-examples` — every pattern `01-basics.js` asks for
- `00b-async-worked-examples` — every pattern `02-async.js` asks for

They all use books rather than blog posts, so nothing in them pastes straight into an
answer. Read one, then go do the exercise file it pairs with.

Do not look up the answers themselves. Getting a FAIL and reasoning about why is the
entire point — these are the exact patterns that will otherwise look like magic
when you meet them inside a React component or a Django model.

Reference while you work:

- [MDN JavaScript guide](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide)
- [MDN array methods](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array)
- [Python classes tutorial](https://docs.python.org/3/tutorial/classes.html)
- [Python regex howto](https://docs.python.org/3/howto/regex.html)
